## GitHub'ga joylash
1. Yangi repo yarating: `itcodeuz`
2. Uchala faylni yuklang (Add file → Upload files)
3. Settings → Pages → Branch: `main` / `root` → Save
4. 1–2 daqiqadan keyin sayt ochiladi
